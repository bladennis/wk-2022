## 📋 About

A interactive data visualization of the ongoing 2022 FIFA World Cup.

Its created using a external dataset which is cleaned and transformed into a more usable format. The data is then visualized using D3.js and GSAP for experimental animations. The project is built using Vite and SCSS for styling.

## 💻 Installation

install this repository: 

```
git clone https://github.com/bladennis/wk-2022.git
```

To install Node modules:

```
npm install
```

To run the application:

```
npm run dev
```
